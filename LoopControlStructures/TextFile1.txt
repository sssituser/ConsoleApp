		1.While : It is an Entry Controlled Structure, Since before executing while block
		statements compiler the checks the condition first , 
		if the condition is true it executes while block statements and then continues, if its false
		it comes of the while block.

		syntax : While(con)
				{
					stmts;	
				}
				
				
				case 1 : con true compiler executes the stmts till the con is false.
				case 2 : con false compiler will not execute while block statements.
