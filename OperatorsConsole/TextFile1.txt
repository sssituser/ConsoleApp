Conditional Statements or Control Statements
1. Simple if  :
				if(con)
				{
					stmts;
				}
				In the above syntax
				1. con - True  Compiler Executes stmts
				2. con - False Compiler Will not Exeute stmts

2. if-else
			if(con){
				stmts-1;
			}else{
				stmts-2;
			}
			1. con-True  Compiler executes stmts-1
			2. Con-False Compiler executes stmts-2



3. Nested if
			if(con-1){
				if(con-2){
					stmts-1;
				}else{
					stmts-2
				}

			}else{
				stmts-3
			}
			1. con1-True con2-True  stmts-1 can be executed.
			2. con1-True con2-False stmts-2 can be executed.
			3. con1-False stmts-3 can be executed

4. else-if ladder
		if(con-1){
			stmts-1;
		}else if(con-2){
			stmts-2;
		}else if(con-3){
			stmts-3;
		}
		....
		....
		else{
			stmts
		}


5. switch 
					
					It is called Selection Statement
					switch(const){
						case 1:
							stmts-1;
							break;
						case 2:
							stmts-2;
							break;
						case 3:
							stmts-3;
							break;
						.....
						......
						default :
							stmts;
							break;
					}


6. goto
		It order to move the compiler in the program during the execution we use
		goto.

		goto can control the compiler in the program.

			It is called as jumping statement
			goto label:
				stmts-1
			label:
				stmts-2
